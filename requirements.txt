# RetinaFace via InsightFace (preferred).
#
# onnxruntime-gpu, NEVER plain onnxruntime, and never both. Both install into
# the same site-packages/onnxruntime and the CPU build wins, which is a SILENT

# `onnxruntime` — cosmetic: onnxruntime-gpu provides that module, pip just
# cannot see the distribution name. See CLAUDE.md section 1.

# Langfuse — LLM tracing/usage/cost for `backend/tracing.py`. Optional at
